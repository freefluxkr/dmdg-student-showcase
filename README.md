# 심화 : 심층 데이터 분석을 통한 개인 맞춤형 예측 자동화 서비스 솔루션 개발과정의 단계별 프로젝트들 발표자료 서비스

DMDG 교육과정 수강생들의 단계별 프로젝트 발표 자료, 시연 영상, 4페이지 기술 감사 피드백 리포트(PDF) 및 전체 원천 자료를 웹에서 즉시 열람하고 다운로드할 수 있는 **오로라 테마(Aurora Glassmorphism) 공개 대시보드**입니다.

## 주요 구성 (3단계 탭)
1. **데이터 분석 1차 프로젝트** (6개 프로젝트 및 200점 평가 기준표)
2. **미니 프로젝트 발표자료** (8개 프로젝트)
3. **최종 프로젝트 기획안** (4개 최종 기획서)

## 호스팅 구조
- **GitHub Pages (`gh-pages` 브랜치)**: 정적 오로라 대시보드, 슬라이드/노트북/문서 웹 프리뷰, 피드백 PDF(19종), 35MB 이하 산출물
- **GitHub Releases (`v1.0-assets`)**: 대용량 원천 데이터셋(CSV 19종, 1.38GB), 고화질 시연 영상(MP4), AI 오디오 브리핑(M4A) 및 프로젝트별 일괄 ZIP 패키지
