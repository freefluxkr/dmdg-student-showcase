[Slide 2] 문제 제기 (Why Now? Pain Points)

- 사회가 디지털화 되는 동시에 초고령화 사회 진입 예정이나, 시니어 친화적인 서비스가 많지 않음

[Slide 3] 솔루션 정의 (What is Card-FDS-N?)

- AI Hub 카드거래 합성데이터를 이용하여 고객의 소비 패턴, 지역, 거래날짜 등 다차원 데이터를 분석하고, 머신러닝 기반으로 개별 거래의 이상 가능성을 판별

- 권장 기술 스택에 대해 설명

[Slide 4] 엔드투엔드 시스템 아키텍처 (System Architecture)

- AI Hub 카드거래 CSV 파일 로드(분기별 CSV 파일 통합 스키마, 라벨, 결측 점검 학습, 검증 데이터 따로 분석)→ 품질 점검 및 전처리(결측값 처리, 자료형 정리, 파생병수 생성 모델 입력 피처) → SMOTENC 및 클래스 가중치(학습 데이터에만 SMOTENC와 클래스 가중치를 적용하고 세 모델 학습 LightGBM, Random Forest, XGBoost 모델 성능 비교) → 3개 분류 모델 및 2개 앙상블 위험 확률 산출(Validation 원본 분포에서 단일 모델과 확률 평균 앙상블 평가 성능표, 위험 확률, 최종 모델)

[Slide 5] LightGBM*Random Forest, LightGBM*XGBoost 앙상블 (Modeling)

- SMOTENC 적용 전/후 및 단일 모델 vs 앙상블의 Minority F1-Score 비교 테이블 산출
