7장. 두 분석 결과를 학습한 결합 점수로 기본 예측

핵심 메시지:
정답 라벨로 학습한 가중치를 이용해 LightGBM 점수와 YARA 매칭 여부를 결합한다.

슬라이드 내용:
입력 x1: LightGBM 악성 예측 점수
입력 x2: YARA-X 하나 이상 매칭 1 / 미매칭 0
학습: 301개 표본, L2 정규화 로지스틱 회귀
z = -3.59571 + 6.05222 × x1 + 0.07768 × x2
결합 점수 = 1 / (1 + exp(-z))
현재 기본 예측:
- 결합 점수 >= 0.5: 악성 의심
- 결합 점수 < 0.5: 정상 예측 · 안전 보장 아님
- 입력 검사·모델 해시 확인 실패: 판정 불가

추천 시각 자료:
입력 두 개 → 로지스틱 회귀 → 결합 점수·예측 카드. 실제 계수는 표 또는 작은 수식 상자에 넣는다.

발표자 설명:
이 수치는 실제 학습된 모델의 계수이며 임의 배점이 아닙니다. 기본 화면의 예측은 이 결합 점수로 결정합니다. 정상 예측은 안전을 보장하지 않으며 점수는 실제 악성 확률로 보정된 값이 아닙니다. YARA 양성은 1건뿐이라 계수의 일반화에는 한계가 있습니다. YARA 매칭이 0일 때 0.5 결합 기준은 LightGBM 점수 약 0.59411을 기준으로 나누는 것과 같습니다.

작성 주의사항:
초기 4피처 로지스틱 회귀와 별개 모델이다. 실제 계수와 LightGBM 특징 기여도를 혼동하지 않는다. 검증 완료를 운영 안전성 입증으로 표현하지 않는다. 0.5는 현재 적용한 실험 기준이며 검증으로 최적화한 운영 임계값이 아니다. 수식의 계수는 소수점 다섯 자리로 반올림한 값이다.
