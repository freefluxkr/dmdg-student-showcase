9장. 업로드부터 기본 예측·근거 확인·보고서 저장까지

핵심 메시지:
분석 흐름을 Streamlit 웹사이트로 구현해 파일별 결과를 확인할 수 있게 한다.

슬라이드 내용:
지원: I386 PE32 EXE/DLL, 비-.NET, 최대 32 MiB
구현: Python · Streamlit · LightGBM · EMBER2024 · YARA-X · scikit-learn
요약 카드: LightGBM 점수 / YARA 일치 규칙 수 / 검사 완료 / 기본 결합 점수
탭 5개:
1. 쉬운 결과 설명
2. 모델이 참고한 특징
3. YARA-X 탐지 근거
4. 로지스틱 회귀 결합: 입력·수식·평가 결과
5. 파일 정보·보고서: SHA256·추출 정보·JSON 다운로드
- 파일 변경·실패 시 이전 결과 제거
- 업로드 원본은 메모리 처리, 실행·외부 전송 없음
- JSON에 실제 결합 점수·판정·임계값·모델 해시 포함

추천 시각 자료:
최신 웹사이트 실제 화면을 크게 배치한다. 결합 점수·판정, 특징 그래프, 규칙 근거, 보고서 저장 영역을 표시한다. 이 텍스트에는 화면 캡처가 포함돼 있지 않다.

발표자 설명:
웹사이트는 파일을 실행하지 않고 분석하며 기본 예측은 학습된 결합 모델을 사용합니다. 동시에 LightGBM 점수와 YARA 결과를 독립적으로 확인할 수 있습니다. 검사 실패는 미매칭으로 바꾸지 않고 판정 불가로 처리합니다. 결과는 브라우저 세션에 유지되며 사용자가 JSON으로 내려받을 수 있습니다. 서버에 분석 결과가 자동 누적 저장되는 기능은 아닙니다.

작성 주의사항:
64비트·.NET·동적 분석·capa·서명 신뢰 검증을 기본 지원 기능으로 표시하지 않는다. JSON에 원본 EXE가 들어간다고 설명하지 않는다. 정상 예측은 안전 보장이 아니다.
