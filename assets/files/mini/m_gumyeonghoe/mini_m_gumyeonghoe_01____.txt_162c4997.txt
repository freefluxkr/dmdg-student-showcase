발표 방향: 설계 목적 → 구조 → 데이터 → 개별 분석 → 결합 모델 → 근거 설명 → 웹 구현 → 평가 → 결론의 흐름으로 구성한다. 개발 도중의 변경 이력은 다루지 않는다. 기능 구현 사실과 관측 성능을 구분한다. 실제 결합 모델은 웹 기본 예측에 사용 중이며 운영 안전성을 입증한 모델이라는 뜻은 아니다.
시각화 원칙: 실제 자료가 없는 화면·기여도·패턴 위치·성능 수치는 만들지 않는다. 본문은 짧게, 발표자 설명과 작성 주의사항은 참고 정보로 사용한다.

1장. LightGBM·YARA-X·로지스틱 회귀 기반 실행파일 정적 분석 대시보드

핵심 메시지:
통계적 특징과 악성 패턴 검사 결과를 결합하고, 판단 근거를 확인할 수 있는 웹사이트를 구현한다.

슬라이드 내용:
- Windows 실행파일을 실행하지 않고 정적으로 분석
- LightGBM: 528개 피처로 악성 예측 점수 산출
- YARA-X: 알려진 악성 패턴 검사
- 로지스틱 회귀: 두 결과를 결합한 기본 예측
- 웹 대시보드: 점수·특징 기여도·규칙 근거·JSON 보고서

추천 시각 자료:
실행파일 → 두 분석 경로 → 결합 모델 → 설명 가능한 대시보드의 간결한 개념도를 배치한다.

발표자 설명:
이 프로젝트는 파일의 통계적 특징과 구체적인 패턴을 서로 다른 관점에서 분석합니다. 그 결과를 로지스틱 회귀로 결합해 예측하고, 사용자가 개별 분석 근거도 함께 확인하도록 구현했습니다. 결합 결과는 실험용 예측이며 실제 악성 여부를 보장하는 백신은 아닙니다.

작성 주의사항:
성능 향상을 달성했다는 표현을 사용하지 않는다. 구현 성과와 탐지 성능 검증을 구분한다.
